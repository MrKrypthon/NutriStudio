# Flujo de consulta nutricional

## 1. Agenda

- Sugerencia de horario
- Pedir que traigan estudios en caso de tener

## 2. Consulta

- **Datos del paciente**
  - Fecha de nacimiento
  - Ocupación
- **Motivo de consulta**

### 2.1 Antropométrico

- Mediciones (hay varios tipos de mediciones y se aplican fórmulas)

### 2.2 Bioquímico

Son los estudios de laboratorio con sus interpretaciones.

- Son opcionales en la primera consulta
- Se sugiere realizarlos y se traen en la 2da consulta
  - → Se guardan en el expediente

### 2.3 Clínico

- Antecedentes familiares
- Enfermedades
- Cirugías realizadas
- Medicamentos
- Suplementos
- Interacciones entre medicamentos/suplementos con nutrientes
- Alergias/intolerancias
- Tabaco y/o alcohol → si consume y frecuencia
- Síntomas
- Exploración física

### 2.4 Dietético

- Cuántas comidas realiza en un día y a qué hora
- Comidas/bebidas preferidas
- Alimentos que no son de su agrado o que le causan malestar
- Cuántos vasos de agua toma al día
- A qué hora tiene más hambre
- Habrá asistido a consulta nutricional
  - → ¿De qué tipo?
  - ¿Por cuánto tiempo llevó la dieta?
  - ¿Por qué razón la llevó?
  - ¿Notó algún resultado?
  - ¿Qué tanto se apegó a la dieta?

#### Continuación 2.4

- **Frecuencia de alimentos**
  Es la cantidad de días a la semana que consume cada uno de los alimentos (leche, queso, carne de pollo, avena, tortilla, etc.).

- **Dieta habitual**
  El paciente describe lo que come normalmente en sus desayunos, colaciones, almuerzos y cenas con cantidades (si recuerda) y horarios.

- **Recordatorio 24 horas**
  El paciente describe lo que comió el día anterior en cada tiempo de comida (desayuno, colaciones, almuerzo y cena) con horarios y cantidades.

  El software toma esa info y suma las calorías, gramos de proteína, carbohidratos, grasas (lípidos), ácidos grasos saturados, ácidos grasos monoinsaturados, ácidos grasos poliinsaturados, colesterol, azúcar, fibra, vit. A, vit. C, vit. B9, calcio, hierro, potasio, sodio y fósforo.

  Compara esa info con las cantidades ideales por sexo y grupo de edad, calcula un porcentaje de adecuación **((consumo ÷ ideal) × 100)** y:
  - si sale **< 95 %** interpreta **"Bajo"**
  - **95–105 %** → **"Normal"**
  - **> 105 %** → **"Alto"**

### 2.5 Estilo de vida

- Actividad física
- Sueño
- Estado de ánimo/estrés
- Jornada laboral
- Otros

### 2.6 Sociocultural

- Se pregunta si hay barreras económicas para el plan, para saber presupuesto
- Entorno familiar, laboral
- Prácticas o restricciones religiosas o culturales

### 2.7 Diagnóstico nutricional

- **CESIVA**
  Acá vería una tabla para que yo llene:

  | Criterio    |   |
  |-------------|---|
  | Completa    |   |
  | Equilibrada |   |
  | Suficiente  |   |
  | Inocua      |   |
  | Variada     |   |
  | Adecuada    |   |

- **Tipo de dieta**
  Acá se evalúa la alimentación del paciente.

- **Diagnóstico**
  Se analizan los problemas nutricionales, se asocia a una causa (etiología) y se evidencia o comprueba con los signos o síntomas que tiene el paciente.

### 2.8 Tratamiento o intervención

- Objetivos: se hacen con base al diagnóstico
- Metas SMART, barreras y soluciones
- Recomendaciones dietéticas clave
- Suplementos
- Educación alimentaria
- Acuerdos con el paciente
- Próximos pasos

## Cierre de la consulta

Acá acaba la consulta, le doy clic a **[Terminar consulta]**, escribo el monto de la consulta y selecciono el método de pago y luego le doy a **[Terminar y registrar →]**.

Luego le pregunto al paciente qué día quisiera tener su siguiente cita. Le doy clic al botón **[Agendar]** y lleno la información, luego le doy a **[Crear cita]**.

Me despido del paciente.

Luego le doy clic a **descargar expediente**.
